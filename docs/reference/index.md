The pages in this group are lookup tables rather than guides. They are the source of truth for the values they list; the guides in [Configuration](../configuration/index.md) and [Deployment](../deployment/index.md) link here instead of repeating them.

| Page | Use it when |
|---|---|
| [Environment variables](./environment-variables.md) | You are filling in a `.env` file or wondering what a variable does and what its default is. |
| [Background jobs](./background-jobs.md) | You want to know what runs on a schedule, what a queue name in the logs means, or why something is delayed. |
| [CLI](./cli.md) | You need to run a maintenance command by hand. |
| [Ports and services](./ports-and-services.md) | You are opening firewall rules or reading `docker-compose.yml`. |
| [Troubleshooting](./troubleshooting.md) | The server refuses to start, sync does nothing, or emails never arrive. |
